# Kullanılan Teknolojiler

[← README'ye dön](../README.md)

## Backend
| Teknoloji | Amaç |
|---|---|
| PHP 8.4 | Çalışma ortamı |
| Laravel (11/12 nesli) | Uygulama çatısı (framework) |
| Laravel Sanctum | API token tabanlı kimlik doğrulama |
| MySQL 8.4 | Veritabanı |
| NetGSM REST API | SMS gönderimi |
| Laravel Scheduler | Zamanlanmış hatırlatma SMS'leri |

## Frontend
| Teknoloji | Amaç |
|---|---|
| React 19 | Arayüz kütüphanesi |
| TypeScript | Tip güvenliği |
| Vite | Geliştirme sunucusu / build aracı |
| Tailwind CSS v4 | Stil / tasarım sistemi |
| React Router | Sayfa yönlendirme (routing) |
| Axios | API istekleri |
| FullCalendar | Takvim görünümü |
| Recharts | Dashboard grafikleri |
| lucide-react | İkonlar |

## Altyapı
| Teknoloji | Amaç |
|---|---|
| Docker / Docker Compose | Tüm servislerin izole, tekrarlanabilir ortamı |
| Nginx | Backend için web sunucusu |
| phpMyAdmin | Veritabanını görsel yönetme aracı |
